Como esses números foram calculados

O que é medido e o que é estimado. Quantos votos cada candidato teve em cada um dos 94.708 locais de votação, nos dois turnos, é dado oficial do TSE — são as barras. Para onde foi cada eleitor não está em nenhum lugar: o voto é secreto. As faixas são uma estimativa feita por regressão, comparando como o resultado mudou entre os dois turnos em locais de perfil político diferente, dentro de cada estado.

O limite honesto da estimativa. Com dado agregado por local, dois movimentos opostos que se anulam dentro do mesmo local são invisíveis — é a chamada falácia ecológica. O que o diagrama mostra é o fluxo líquido: o menor remanejamento de votos compatível com o que cada local registrou nas duas datas. Por isso a lealdade de cada candidato aparece como um teto, e a troca entre candidatos, como um piso.

A faixa de incerteza. Cada número vem com uma faixa de 95%, obtida reamostrando os 5.715 municípios da base 150 vezes. Faixa larga significa que o dado não decide aquela célula — caso de boa parte dos votos brancos e nulos, cujo movimento é pequeno e disperso. Onde a faixa é estreita, o resultado é robusto.
